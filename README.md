# Markdown server

A Markdown server for code documentation with different themes as compiler flags, source code highlighting, and the usual Markdown formatting.

<img src="md/example.png" alt="Description" style="width: 100%; height: auto;">

# build and config

----

cargo run --no-default-features --features theme-green-black

cargo run --no-default-features --features theme-light-modern

cargo run --no-default-features --features theme-black-white

cargo run --no-default-features --features theme-dark-blue

----
